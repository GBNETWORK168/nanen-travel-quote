# 國旅報價系統

富邦產險「新快樂旅綜＋　國旅限定版」115.10版的內部報價頁。純靜態、手機友善。

- 公開網址：https://gbnetwork168.github.io/nanen-travel-quote/domestic/
- 費率只使用 DM 刊印的 1～20 日數字，不內插。
- 只填日期時，起日與迄日都算進去；起迄都有時刻時，按時數換算整天（未滿一日以一日計）。
- 可多人、不同計畫加總，並一鍵複製報價文字。
- 不送審、不出單、不付款。保費若與公司系統有差異，以系統為準。

此頁與既有「旅平險組合方案試算」（國外／壽＋產）分開，不改動原 editor.html、index.html 行為。
